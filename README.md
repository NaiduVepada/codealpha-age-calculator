# Age Calculator - CodeAlpha Internship Task

This is a simple web-based Age Calculator created for the CodeAlpha Web Development Internship.

## 💻 Built With:
- HTML
- CSS
- JavaScript

## 🚀 Features:
- Calculate age based on user’s date of birth.
- Validates input for past/future dates.
- Responsive and user-friendly design.

## 🎯 How to Use:
1. Enter your **Day**, **Month**, and **Year** of birth.
2. Click **Calculate Age**.
3. Your age will be displayed instantly.
